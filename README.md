# Bảo Ngọc – bản phát hành app desktop

Kho này chỉ chứa **bản cài đặt** của app khám – tư vấn – hội chẩn nha khoa từ xa (Windows).
App đã cài tự kiểm tra và cập nhật từ mục [Releases](../../releases) (file `latest.json`).

- Tải bản mới nhất: [Releases → Latest](../../releases/latest)
- Mỗi bản cài được ký số; app chỉ nhận bản có chữ ký hợp lệ.

Mã nguồn không nằm ở đây.
